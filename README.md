# Portfolio - Sol Prinzen
*Práctica Formativa de la materia Desarrollo de Sistemas Web (Front End)*
> Sitio web personal y portfolio profesional desarrollado con HTML5, CSS3 y Bootstrap 5, diseñado para presentar proyectos de desarrollo Web y Mobile.

**Link al sitio web:** [Ver Portfolio en Vercel](https://portfolio-sol-prinzen.vercel.app/)

## Tecnologías Utilizadas

* **HTML5:** Maquetación semántica y estructuración del contenido.
* **CSS3:** Estilos personalizados, tipografías y ajustes de componentes.
* **Bootstrap 5.3:** Grilla responsiva, componentes nativos y utilidades de Flexbox.
* **Google Fonts:** Tipografías
* **Font Awesome 6:** Iconografía para redes sociales y badges de tecnologías.
* **Formspree:** Integración para el envío funcional de formularios sin backend.


## Declaración de Uso de Inteligencia Artificial

En cumplimiento con el requisito transversal de la consigna, se detalla el uso de herramientas de IA generativa durante el desarrollo de este proyecto:

* **Herramientas utilizadas y propósito:** 
  * **Gemini:** Utilizada como asistente de código para maquetación en HTML5/CSS3, resolución de inconvenientes con el grid responsivo de Bootstrap 5, configuración y prueba técnica del envío del formulario de contacto y organización de la jerarquía visual de los proyectos.
* **Plan utilizado:** 
  * Plan 100% gratuito.
* **Experiencia previa con la herramienta:** 
  * Intermedia. Utilizada habitualmente como soporte de maquetación UI, consulta de sintaxis y diagnóstico de errores en desarrollo Frontend.

* **Revisión, cambios y criterio propio aplicado:**
  * Revisé el HTML línea por línea para detectar y corregir errores a mano
  *  Definí por mi cuenta la estética de la página, los colores, las tipografías, los espaciados y el ajuste de las imágenes en las tarjetas.
  * Inserte manualmente toda la información de mis proyectos, las capturas de pantalla y los links a mis repositorios de GitHub, demos web y prototipos de Figma.
  * Descarté propuestas de la IA que sumaban animaciones complejas, scripts extras o código innecesario, buscando mantener una maqueta limpia, ligera y enfocada en la consigna.
  * Usé la IA como apoyo para estructurar y redactar este archivo, ajustando cada texto con mi propio criterio para que refleje de forma transparente cómo trabajé.
